# 🛡️ Система Локального Прокторинга (Proctoring CV + Security)

Комплексный программный комплекс защищенного онлайн-тестирования для хакатона с мультимодальным анализом поведения студента в реальном времени и аппаратной защитой рабочего окружения операционной системы Windows.

---

## 🚀 Основные возможности

### Модуль А: Детекция смартфона и посторонних предметов
* **Нейросетевой инференс:** Интеграция `ultralytics YOLOv8` (класс `cell phone`, COCO ID 67) с оптимизированным разрешением для CPU/GPU инференса на 25–30 FPS.
* **Анализ зон риска (Spatial Risk ROI):** Контроль нахождения смартфона в верхних 70% кадра перед экраном и расчет евклидова расстояния до овала лица (proximity check).
* **Временной анти-фликкеринг (Debouncing):** Использование скользящего окна ($N \ge 5$ кадров) для отсечения единичных ложноположительных артефактов.

### Модуль Б: Оценка позы головы (Head Pose), взгляда (Gaze) и контроль лиц
* **MediaPipe FaceMesh:** Трекинг 468 ключевых точек лица в 3D + 10 точек радужки (Iris Tracking).
* **Head Pose Estimation via `cv2.solvePnP`:**
  * Сопоставление 6 канонических точек лица (кончик носа, подбородок, внешние углы глаз, уголки губ) с эталонной 3D-моделью головы.
  * Расчет углов Эйлера (**Yaw**, **Pitch**, **Roll**) в градусах относительно нейтрального взгляда в центр монитора.
  * Порог поворота головы: $|Yaw| > 38^\circ$ (свободный обзор краев широкого монитора без ложных срабатываний).
  * Порог наклона вниз: $Pitch < -30^\circ$ (естественный наклон при чтении текста не считается нарушением).
  * Порог наклона вверх: $Pitch > 30^\circ$.
* **Gaze Tracking:** Отношение смещения зрачка относительно внутренних и внешних уголков глаз (горизонтальный и вертикальный вектор взгляда).
* **Контроль присутствия:**
  * 0 лиц в кадре $\to$ триггер `NO_FACE` («Студент покинул рабочее место»).
  * $>1$ лица в кадре $\to$ триггер `MULTIPLE_FACES` («Постороннее лицо в кадре»).
* **Временные фильтры нарушений:** естественные микродвижения и моргание игнорируются; тревога срабатывает только при непрерывном отклонении $> 1.5$ сек.

### Модуль В: Защита окружения (Kiosk Mode & OS Security)
* **Полноэкранный Kiosk-режим:** окно разворачивается во весь экран (`showFullScreen()`) с флагом `WindowStaysOnTopHint` без рамок (`FramelessWindowHint`).
* **Низкоуровневый WinAPI хук клавиатуры (`WH_KEYBOARD_LL`):**
  * Подавление системных переключателей: `Alt+Tab`, `Alt+Esc`, `Win Key` (Start Menu), `Ctrl+Esc`.
  * Блокировка диспетчера задач и закрытия: `Alt+F4`, `Ctrl+Shift+Esc`.
  * Блокировка скриншотов: `PrtScn` (`VK_SNAPSHOT`).
  * Блокировка буфера обмена: `Ctrl+C`, `Ctrl+V`, `Ctrl+X`.
* **Мониторинг фокуса окна (`GetForegroundWindow`):**
  * При потере фокуса окно блокируется защитной шторкой с предупреждением и фиксацией инцидента `FOCUS_LOST`.
  * Принудительный возврат фокуса в окно тестирования (`SetForegroundWindow`).
  * Полное отключение контекстных меню мыши.

### Модуль Г: Журналирование и визуальный HUD
* **Автоматическое сохранение улик:** при каждом инциденте аннотированный кадр высокого разрешения сохраняется в `logs/incidents/<timestamp>_<type>.jpg`.
* **Двойное структурированное логирование:**
  * `logs/incidents.jsonl` — построчный машиночитаемый JSON.
* **Свободный выход без пароля:** завершить тестирование и выйти из системы можно прямо с экрана результатов по кнопке «🚪 Выйти из программы» или по клавишам `Esc` / `Ctrl+Alt+Shift+F12` без ввода пароля администратора.
* **Интерфейс тестирования (Чистый Kiosk UI):**
  * **Стартовый экран (Вход):** название «Система локального прокторинга», поле ввода ФИО студента, регламент тестирования и крупная кнопка «Начать тестирование →».
  * **Экран тестирования:** шапка (ФИО студента, вопрос «Вопрос 1 из 10», таймер «⏱️ 15:00»), стилизованная карточка вопроса, нижняя панель («← Предыдущий», «Следующий →», «Завершить 🏁»).
  * **Компактная камера-миниатюра (PiP):** аккуратное превью 240x175 в нижнем углу с закругленными углами 14px и лаконичным русскоязычным индикатором: 🟢 «Всё в норме» / 🟡 «Внимание» / 🔴 «Нарушение» / ⚪ «Тест завершен» (без отладочного мусора и координат).
  * **Экран результатов:** итоговые баллы (например, «8 / 10»), процент успеха, вердикт прокторинга (🟢 «Тест сдан честно» / 🔴 «Зафиксированы нарушения»), детальный разбор каждого вопроса и кнопка «🚪 Выйти из программы».
* **Гарантированное освобождение ресурсов при выходе:**
  * Безопасная остановка потока видеозахвата и освобождение веб-камеры (`cap.release()`).
  * Мгновенное снятие глобального WinAPI-хука клавиатуры (`UnhookWindowsHookEx`), возвращающее ОС в штатный режим.
  * Корректная остановка дочерних потоков без зависания процесса в Диспетчере задач Windows.

## ⚙️ Как запустить проект в один клик (Demo Day)

### 1. Запуск в 1 клик на Windows
Двойным кликом запустите файл **`run.bat`** в корне папки проекта.  
Скрипт автоматически активирует виртуальное окружение `.venv` (если создано) либо системный Python и запустит `main.py`:
```bat
@echo off
python main.py
pause
```

### 2. Запуск на Linux / macOS
```bash
chmod +x run.sh
./run.sh
```

### 3. Запуск через терминал (с параметрами)
```powershell
# Полноэкранный защищенный Kiosk-режим:
.venv\Scripts\python main.py

# Оконный режим (для отладки/презентаций):
.venv\Scripts\python main.py --windowed

# Режим виртуальной камеры (если нет веб-камеры):
.venv\Scripts\python main.py --windowed --mock
```

## 🔑 Сценарий прохождения для Demo Day

1. **Экран входа:**
   * Введите ФИО студента (или нажмите Enter для демонстрационного профиля).
   * Ознакомьтесь с регламентом (15 минут, 10 вопросов).
   * Нажмите **«Начать тестирование →»**.

2. **Экран тестирования:**
   * Таймер начинает обратный отсчет (15:00).
   * В верхнем правом/нижнем углу отображается аккуратное превью камеры с индикатором 🟢 «Всё в норме».
   * При отводе взгляда или головы более чем на 1.5 секунды индикатор временно меняется на 🟡 «Внимание», затем при устойчивом нарушении фиксируется инцидент 🔴 «Нарушение».
   * Отвечайте на вопросы (навигация: «Предыдущий», «Следующий»).
   * На 10-м вопросе появляется красная кнопка **«Завершить тест 🏁»**.

3. **Экран результатов:**
   * Отображается итоговый балл (например, `9 / 10`) и статус сдачи.
   * Выводится официальный вердикт прокторинга:
     * 🟢 **«Прокторинг: Тест сдан честно»** — если нарушений не зафиксировано.
     * 🔴 **«Прокторинг: Зафиксированы нарушения»** — при наличии зафиксированных инцидентов.
   * Доступен подробный построчный разбор каждого вопроса с объяснением правильных ответов.
   * Кнопка **«🚪 Выйти из программы»** безопасно закрывает экзамен, снимает системные хуки и завершает процесс.

## 🧪 Автоматическая проверка перед защитой

Перед презентацией можно мгновенно убедиться в полной работоспособности всех модулей:
```powershell
# Быстрая проверка без GUI (YOLO, solvePnP, FaceMesh, Security):
.venv\Scripts\python quick_test_no_gui.py

# Смоук-тест графического интерфейса и цикла закрытия:
.venv\Scripts\python verify_runtime.py

# Модульные тесты:
.venv\Scripts\python -m unittest tests.test_proctoring tests.test_exam_finish_silence
```
