# 🛡️ Система Локального Прокторинга (Proctoring CV + Security)

Комплексный программный комплекс защищенного онлайн-тестирования для хакатона с мультимодальным анализом поведения студента в реальном времени и аппаратной защитой рабочего окружения операционной системы Windows.

---

## 🚀 Основные возможности

### Модуль А: Детекция смартфона и посторонних предметов
* **Нейросетевой инференс:** Интеграция `ultralytics YOLOv8` (класс `cell phone`, COCO ID 67) с оптимизированным разрешением для CPU/GPU инференса на 25–30 FPS.
* **Анализ зон риска (Spatial Risk ROI):** Контроль нахождения смартфона в верхних 70% кадра перед экраном и расчет евклидова расстояния до овала лица (proximity check).
* **Временной анти-фликкеринг (Debouncing):** Использование скользящего окна ($N \ge 5$ кадров) для отсечения единичных ложноположительных артефактов.

### Модуль Б: Оценка позы головы (Head Pose), взгляда (Gaze) и контроль лиц
* **MediaPipe FaceMesh:** Трекинг 468 ключевых точек лица в 3D + 10 точек радужки (Iris Tracking).
* **Head Pose Estimation via `cv2.solvePnP`:**
  * Сопоставление 6 канонических точек лица (кончик носа, подбородок, внешние углы глаз, уголки губ) с эталонной 3D-моделью головы.
  * Расчет углов Эйлера (**Yaw**, **Pitch**, **Roll**) в градусах относительно нейтрального взгляда в центр монитора.
  * Порог поворота головы: $|Yaw| > 38^\circ$ (свободный обзор краев широкого монитора без ложных срабатываний).
  * Порог наклона вниз: $Pitch < -30^\circ$ (естественный наклон при чтении текста не считается нарушением).
  * Порог наклона вверх: $Pitch > 30^\circ$.
* **Gaze Tracking:** Отношение смещения зрачка относительно внутренних и внешних уголков глаз (горизонтальный и вертикальный вектор взгляда).
* **Контроль присутствия:**
  * 0 лиц в кадре $\to$ триггер `NO_FACE` («Студент покинул рабочее место»).
  * $>1$ лица в кадре $\to$ триггер `MULTIPLE_FACES` («Постороннее лицо в кадре»).
* **Временные фильтры нарушений:** естественные микродвижения и моргание игнорируются; тревога срабатывает только при непрерывном отклонении $> 1.5$ сек.

### Модуль В: Защита окружения (Kiosk Mode & OS Security)
* **Полноэкранный Kiosk-режим:** окно разворачивается во весь экран (`showFullScreen()`) с флагом `WindowStaysOnTopHint` без рамок (`FramelessWindowHint`).
* **Низкоуровневый WinAPI хук клавиатуры (`WH_KEYBOARD_LL`):**
  * Подавление системных переключателей: `Alt+Tab`, `Alt+Esc`, `Win Key` (Start Menu), `Ctrl+Esc`.
  * Блокировка диспетчера задач и закрытия: `Alt+F4`, `Ctrl+Shift+Esc`.
  * Блокировка скриншотов: `PrtScn` (`VK_SNAPSHOT`).
  * Блокировка буфера обмена: `Ctrl+C`, `Ctrl+V`, `Ctrl+X`.
* **Мониторинг фокуса окна (`GetForegroundWindow`):**
  * При потере фокуса окно блокируется защитной шторкой с предупреждением и фиксацией инцидента `FOCUS_LOST`.
  * Принудительный возврат фокуса в окно тестирования (`SetForegroundWindow`).
  * Полное отключение контекстных меню мыши.

### Модуль Г: Журналирование и визуальный HUD
* **Автоматическое сохранение улик:** при каждом инциденте аннотированный кадр высокого разрешения сохраняется в `logs/incidents/<timestamp>_<type>.jpg`.
* **Двойное структурированное логирование:**
  * `logs/incidents.jsonl` — построчный машиночитаемый JSON.
  * `logs/incidents.csv` — сводная таблица для анализа в Excel/BI.
* **Интерфейс тестирования:** Встроенный браузер `QWebEngineView` с полноценным экзаменом на 10 вопросов по Computer Vision и системам ИИ (15-минутный таймер, выбор вариантов, подробный экран результатов с показом верных/неверных ответов и кнопкой выхода).
* **Свободный выход без пароля:** завершить тестирование и выйти из системы можно прямо с экрана результатов, по кнопке «Выход» в верхней панели или по клавишам `Esc` / `Ctrl+Alt+Shift+F12` без ввода пароля администратора.
* **Визуальный HUD:**
  * Верхняя панель: статус прокторинга (Зеленый / Желтый / Красный), количество инцидентов, чистый вид без отладочных координат.
  * Плавающее PiP-окно веб-камеры с чистым видеопотоком без мешающих рамок и векторов.
  * Выпадающий анимированный баннер тревоги.
  * Встроенный просмотрщик журнала инцидентов со скриншотами прямо в приложении.

## ⚙️ Как открыть и запустить проект

### Способ 1: Быстрый запуск в 1 клик (без терминала)
В корневой папке проекта подготовлены готовые командные файлы Windows:
* **`start.bat`** — Запуск в **полноэкранном Kiosk-режиме** (основной защищенный режим экзамена).
* **`start_windowed.bat`** — Запуск в **оконном режиме** (рекомендуется для демонстрации жюри, отладки и проверки).

Просто дважды кликните по нужному `.bat` файлу в Проводнике Windows.

---

### Способ 2: Запуск через терминал (PowerShell / CMD)

Откройте терминал в папке проекта:
```powershell
cd "d:\Project\Local proctoring"
```

#### 1. Основной полноэкранный режим:
```powershell
.venv\Scripts\python run.py
```

#### 2. Оконный режим (удобно для проверки и презентаций):
```powershell
.venv\Scripts\python run.py --windowed
```

#### 3. Режим с виртуальной камерой (если нет физической веб-камеры):
```powershell
.venv\Scripts\python run.py --windowed --mock
```

#### 4. Дополнительные параметры запуска:
* **Выбор другой камеры** (например, внешней веб-камеры с индексом 1):
  ```powershell
  .venv\Scripts\python run.py --camera 1
  ```
* **Отключение системного перехватчика клавиатуры** (удобно при разработке):
  ```powershell
  .venv\Scripts\python run.py --windowed --no-hook
  ```

---

### Способ 3: Быстрая проверка всех модулей без GUI (CLI Тест)
Для моментальной проверки работоспособности нейросети YOLOv8, FaceMesh, solvePnP, таймеров и логгера:
```powershell
.venv\Scripts\python quick_test_no_gui.py
```

## 🔑 Прохождение тестирования и выход (без пароля)

1. **В процессе теста:**
   * Отвечайте на вопросы (навигация кнопками *«← Назад»* / *«Далее →»* или по номерам вопросов сверху).
   * На 10-м вопросе кнопка превращается в красную **«Завершить тест 🏁»**.
2. **После завершения экзамена:**
   * Открывается подробный разбор результатов с показом верных и неверных ответов.
   * **Прокторинг и предупреждения полностью отключаются:** никаких всплывающих баннеров, алертов или блокировок фокуса больше не выводится.
   * Для выхода достаточно нажать большую красную кнопку внизу результатов: **«🚪 Закрыть и завершить работу»**.
3. **Досрочный выход в любой момент:**
   * Нажмите кнопку **«🚪 Выход»** в верхней панели или клавишу **`Esc`** на клавиатуре (выход подтверждается одним кликом, **без ввода пароля**).
   * Комбинация экстренного выхода: **`Ctrl + Alt + Shift + F12`**.

## ⚡ Интерактивная демонстрация для Жюри Хакатона

В нижней части окна расположена специальная панель **«⚡ ДЕМО-СИМУЛЯЦИЯ»**, позволяющая мгновенно продемонстрировать реакцию всех алгоритмов:
* **📱 Смартфон** — симуляция появления телефона в поле зрения камеры.
* **👤 Уход со стула** — проверка срабатывания таймера отсутствия лица (`NO_FACE`).
* **👥 2-й человек** — проверка детекции постороннего лица (`MULTIPLE_FACES`).
* **➡️ Поворот головы** — проверка детекции отвода взгляда вправо (`LOOKING_AWAY`).
* **⬇️ Взгляд вниз** — проверка детекции наклона головы вниз (`LOOKING_DOWN`).
* **🔄 Сброс симуляции** — возврат к реальной веб-камере.
* **📋 Журнал нарушений** — просмотр таблицы зафиксированных инцидентов и открытие скриншотов.
